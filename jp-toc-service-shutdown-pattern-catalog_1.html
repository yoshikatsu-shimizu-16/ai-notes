主要な発見 5点

① 「成長しているのに終了する」が常態

メルカリ カウルは終了告知時点で取引数 前年比170%、LINE LIVEは月間売上 前年比195%、DiDi Foodは終了3ヶ月前に静岡へ新規エリア拡大、LINE Payは終了直前期に初の黒字化（+11.8億円）。撤退トリガーはトレンドではなく絶対規模と機会費用。事業KPIの改善を安全シグナルと読むのは誤り。

② 最も信頼できる兆候は「周辺の剥落」

本体の数値より、サードパーティ連携・スキル・提携サービスが一つずつ消えていくほうが早い。LINE CLOVAは終了の19ヶ月前にABEMAスキルが終了、18ヶ月前に市場シェアが26.3%→1%台へ崩壊。外部の実売データ（BCN等）で観測可能だった。

③ 料金ページの改定は2〜3年前の予告

LINE Payは加盟店手数料を0%→2.45%に改定（2021年10月）した33ヶ月後に終了。「獲得フェーズの終了＝投資の引き上げ」の宣言。Wayback Machineでの料金ページ差分監視が、最も低コストで効く定点観測。

④ 外資子会社は現地兆候がほぼ役に立たない

foodpandaは発表から終了まで約40日、DiDi Foodは35日。現地の活動は直前まで正常、むしろ拡大する。見るべきは親会社の株価・規制・上場ステータス・他国での同時撤退。DiDiの場合は10ヶ月前から中国当局の審査という公開情報があった。

⑤ 「表の理由」の情報量は健全性と反比例

Origami Pay・LINE CLOVA・グノシーQは終了理由を一切説明していない（日程の羅列、あるいは告知自体が存在しない）。逆にゆうちょPayは「強みと考えていた機能を活かせず」と自認、Chompyはピボット先を明示。語られない撤退ほど、内部の毀損が深い。

02

方法と凡例

「表の理由」は終了告知の原文を逐語採取。「裏の理由」は証拠グレードを付す。パターン認定は3事例以上、2件以下は「候補」として区別。

証拠グレード

A有価証券報告書・決算説明資料・適時開示・公式リリース・官報決算公告・行政処分公表文・第三者委員会報告書

B当事者の発言・登壇記事・note・信頼できる報道（一次発表の逐語引用を含む）

C分析者の推論。事実として扱わない

情報源

  • 有報・決算説明資料・適時開示（メルカリ第6/7期有報、PayPay F-1 等）

  • 金融庁・証券取引等監視委員会・関東財務局・個人情報保護委員会の公表文
  • 第三者委員会調査報告書（DeNA、SBIソーシャルレンディング）
  • 当事者のnote・インタビュー（VALU小川氏、ソウゾウ原田氏・松本氏、Chompy大見氏）
  • プレスリリース原文（PR TIMES／@Press／各社IR）

P1

資本力勝負（Burn Rate War）

認定 · 6件
文脈
両面ネットワーク効果が強く、勝者総取りに近い市場。決済、フードデリバリー、スマートスピーカー。先行者利益ではなく規模の閾値が勝敗を決める。
症状
売上に対して桁違いの営業赤字。Origami Payは売上2.98億円に対し営業損失41.7億円（売上の14倍）。LINE Payは「300億円祭」の年に純損失208億円。還元キャンペーンの規模だけが競合との唯一の差別化変数になっている。
根本原因
ユーザー獲得コストを、手数料収入で回収するまでの期間が資本の残存期間を超えている。独立系スタートアップはバランスシートの深さで負け、外資子会社は本社のポートフォリオ判断で切られる。どちらも自社の努力で解けない。
兆候
最終ラウンドから18ヶ月の調達途絶／官報の減資公告／大型還元キャンペーンの消滅／人員の大量離脱／親会社の他国での同時撤退
回避策
①「勝者総取り市場に、2番手の資本で入らない」を投資判断の門にする。②還元の設計を1回上限の引き下げ×期間の引き延ばしに振る（PayPay第2弾の1回上限1,000円）。③決済単体で儲けず、隣接の高テイクレート領域へ収益源をずらす（PayPayのカード・銀行・証券）。
該当事例
Origami Pay / LINE Pay / LINE CLOVA / foodpanda日本 / DiDi Food日本 / Chompy
P2

ユニットエコノミクス不成立

認定 · 6件
文脈
需要に比例して変動費が増える事業。配達員報酬、賞金、医師報酬、無料提供の原価。伸びるほど赤字が拡大し、伸びを止めると存在価値が消える。
症状
Chompyは配達員報酬800円/配達に対しユーザー送料300円＋店舗手数料30%——損益分岐の客単価は1,667円、送料無料の「らくとく便」では2,667円。グノシーQは視聴40–50万人に対し参加1.5万人（3%）で、広告枠は1日数百万円が上限。LINEヘルスケアは資本金1.7億円に対し累積損失12.58億円で債務超過。
根本原因
①収益機構が実装されないまま成長させる（メルカリ アッテは「使用料は無料」のまま2年で終了）。②変動費の引き受け手（ユーザー／供給側）に請求できる上限が、市場慣行で固定されている。③品質保証コストと単価がトレードオフになる（医師報酬を払えば赤字、払わなければ炎上）。
兆候
1取引の変動費÷平均注文額が40%超／「送料無料」「手数料無料」を成長施策の中心に置く／無料提供の終了と同時に利用量が落ちる／単独KPIが決算資料に一度も昇格しない
回避策
①ローンチ前に損益分岐の客単価を1本の式で書き、市場の実勢単価と比較する。②変動費を密度で下げる設計（ハブアンドスポーク）は、密度が出る前に大手に塗りつぶされる前提で期限を切る。③収益機構の実装期限を、成長KPIと同格のマイルストーンに置く。
該当事例
メルカリ アッテ / Chompy / グノシーQ / LINEヘルスケア / LINE Pay / Origami Pay
P3

規制未整備（グレーゾーン先行）

認定 · 8件
文脈
既存業法のどれにも明確に当てはまらない設計で先行者利益を取る。疑似株式、時間の証券化、貸付型ファンド、NFT。「禁止されていない」を「許されている」と読み替えた時点で時限爆弾が起動する。
症状
3段階で進行する。T+12〜30ヶ月で当局の見解表明（「監督対象ではないが、まったく無関係とも言えない」型の担当者コメント）、T+αで監視委の勧告または法改正の可決、T+6〜18ヶ月でモデル崩壊。VALUは改正資金決済法の可決（2019年5月31日）から7.5ヶ月後に終了告知。
根本原因
①規制対応コストが調達可能額を超える（VALU：交換業ライセンス取得コストが1億円→20億円に高騰）。②規制回避のために中核価値を自主的に削り、プロダクトが空洞化する（VALUの「優待」廃止）。③規制が要求した匿名化が、そのまま不正の温床になる（ソーシャルレンディングの借り手匿名化）。
兆候
利用規約に該当業法の位置づけが書かれていない／顧客資産を自社で預かる設計で分別管理の説明が公開されていない／中核機能を規制回避目的で自主的に削り始める／同業他社に処分が出る／業界横断の法改正が国会審議入り（可決→施行まで約10ヶ月）
回避策
グレーを利用するのではなく、埋めに行く。LUUPは規制のサンドボックス（2019）→新事業特例（2020）→道交法改正（2022成立・2023施行）と3段階の公的な制度階段を登り、規制所管の国家公安委員会・国土交通省を実証の当事者に引き込んだ。自社の利益ではなく立法事実の供給者として立つのが要諦。
該当事例
VALU / タイムバンク / みんなのクレジット / ラッキーバンク / maneoマーケット / SBIソーシャルレンディング / LINE NFT / リクナビDMPフォロー
P4

組織・ガバナンス不全

認定 · 7件
文脈
質的なゲートを持たない量的KPIが、現場に「最も安価な達成手段」を選ばせる。M&Aで取得した事業を、リスク評価なしに全社展開するときに最も起きやすい。
症状
DeNA第三者委員会が認定した通り、「買収によりキュレーション事業へと新規参入する段階で、同事業に関する分析・議論が尽くされず、事業リスクが適切に把握されなかった」。WELQ含む10サイトで調査対象376,671記事、著作権侵害の可能性1.9〜5.6%、画像は474万個中74万個以上。ソーシャルレンディング4社は全社が「虚偽表示・誤解を生ぜしめる表示」で処分され、全社が関係会社・親族会社への集中貸付という同一構造を持つ。
根本原因
①評価基準に品質・適法性の項目がない（報告書「設定された目標・評価基準の問題」）。②法務部が事業実態に関与せず、チェックが制度として存在しない。③「"反・大企業病"に対する行きすぎた称揚」——慎重さをスティグマ化する文化が内部警告を封じる。④プラットフォーム型は「営業者に一任」で責任を分散できると誤認する（maneoは自ら貸付先を選んでいないのに処分された）。
兆候
記事単価・外注単価が検証工数を構造的に不可能にする水準／生産量の伸び率が監修体制の増員率を大きく上回る／法務部への事業部からの照会件数がほぼゼロ／第三者委員会の設置公表（SBI SLは設置から撤退まで4ヶ月）／上場親会社の開示に「連結業績への影響は軽微」と書かれる
回避策
①量的KPIには必ず同格の質的ゲートを置く（監修者1人あたり生産量の上限）。②M&Aのデューデリジェンスに「取得するビジネスモデルの違法性リスク」を独立項目として入れる。③法務照会件数を牽制機能の稼働指標として経営が見る。
該当事例

P5

親会社の戦略転換

認定 · 11件（最多）
文脈
単体の事業KPIとは無関係に、グループの資本配分判断で終了が決まる。経営統合後の重複整理、合弁の解消、上場直後のポートフォリオ再編。本カタログで最多の死因。
症状
赤字が改善していても終了する。LINE Payは終了直前期（2025年3月期）に初の黒字転換（+11.8億円）。LINE LIVEは月間売上 前年比195%を発表した17ヶ月後に終了告知。J.ScoreとLINEヘルスケアは合弁解消により消滅。告知の語彙は「経営資源の集中／再配置」「選択と集中」「一本化」に収斂する。
根本原因
①グループ内カニバリゼーション（PayPay×LINE Pay、GYAO!×LINE LIVE、J.Score×LINE Credit）。②配布チャネルの割り当て変更——LINEアプリ本体内の一等地がLINE VOOMに与えられた時点で、独立アプリのLINE LIVEはチャネル劣位に落ちた。③親会社のKPI設計：メルカリは単一セグメント開示のため、新規事業の損益はそもそも開示されず、評価は「絶対規模とグループ親和性」で行われる。
兆候
本体アプリ内に競合機能が実装される（17ヶ月前）／親会社の経営統合完了（24ヶ月前）／「終了するアプリ／サービス一覧」の一括公表（4–5ヶ月前）／有報「事業の内容」本文からサービス名が消える／KPI定義注記で「〜は含んでおりません」と過去形で一括除外される／事業系統図から「影響僅少」として省略される
回避策
①新規事業の立ち上げ時に撤退基準を数値で先に決める（ソウゾウ元代表・原田氏「どこまで赤字事業を続け、どのような状態になれば撤退するか、明確に決めていなかった。辞め時を見失っていた」）。②親会社のKPIが「単独採算」か「経済圏のリテンション装置」かを確認する——ラクマは後者だから10年生き残っている。③取引先としては、親会社の統合発表を自社の契約見直しトリガーに設定する。
該当事例

P6

ブーム依存

認定 · 7件
文脈
カテゴリ自体が一過性の熱狂で立ち上がり、熱狂とともに消える。ライブクイズ、音声SNS、仮想通貨・ICO、NFT、スマートスピーカー、高利回り投資。
症状
決定的な数値はClubhouse。日本MAUは2021年2月の約108万人から4月に約21万人（−81%）へ落ちた一方、日本累計DLは83万→170万（+104.8%）と増え続けていた。つまり新規獲得は効いていて、リテンションがゼロに近かった。LINE CLOVAは市場シェア26.3%（2020年11月）→1%未満（2021年4月以降）。
根本原因
①希少性（招待制・順番待ち）を獲得エンジンにすると、希少性が消えた瞬間に価値が消える。②コンテンツが非蓄積型で再訪理由がない。③在宅需要という外部要因への依存。④打ち手が遅行指標に反応する——ClubhouseはMAU−81%の5ヶ月後に招待制を廃止し、8ヶ月後に日本語対応を「検討中」と発表した。
兆候

回避策

A

PayPay vs Origami Pay / LINE Pay

対照パターン：P1 資本力勝負 ／ 2018.10 –（2026.03 Nasdaq上場）

P1を克服

なぜ同じ罠にかかりながら生き残ったのか

  • A親会社の連結耐久力。ソフトバンク＋ヤフーの合弁として、累計営業赤字 約2,800億円（2019/3期〜2024/3期のJGAAP単体合算）を「連結の一事業ライン」として吸収できた。Origamiは独立系で、同じ規模の出血を支えるバランスシートがなかった。
  • A還元設計の可変性。第1弾100億円キャンペーン（1回上限5万円）は10日間で燃え尽きた。第2弾は1回上限を50分の1の1,000円に切り下げ、期間を3ヶ月に引き延ばした。同じ100億円で「10日間の祭り」から「3ヶ月の習慣形成」へ、予算の時間分散に切り替えている。
  • A無料化→課金の順序。3年間無料で344万カ所のネットワーク効果を作り切ってから、2021年10月に1.60%（マイストア ライトプラン加入時）へ移行。MMD研究所調査では解約意向計21.8%が出たが、実績としては離脱していない——加盟店数は2021年9月の344万カ所超から2025年7月に1,000万カ所超へ純増。課金時点で加盟店にとっての代替コストが既に高すぎた。
  • A薄いテイクレートで黒字化できる原価構造。1取引あたりコスト0.773円、処理能力1,250 TPSの内製基盤（F-1記載）。
  • A決済→金融へのテイクレート移行。PayPayカード1,600万枚、PayPay銀行970万口座・預金2.28兆円、PayPay証券154万口座。高テイクレートのオンラインGMV比率を7%（FY2023）→14%（FY2025）へ倍増。決済単体では儲からないことを前提に、収益源を隣接領域へずらした。

決定的だった意思決定

2019年2月：キャンペーン設計の全面変更。第1弾の「10日で100億円が蒸発」という失敗を、次の四半期に構造として反映した。2021年10月：手数料有料化。解約意向2割を承知のうえで課金に踏み切り、実際には離脱が起きないことを検証した。

C

note vs WELQ

対照パターン：P4 組織・ガバナンス／P7 ブランド毀損 ／ 2014 –（2022.12 東証グロース上場）

P4を克服P7を克服

なぜ同じCGMでありながら品質崩壊しなかったのか

  • B収益モデルが広告ではなく課金。加藤貞顕CEO「noteの運営者としての我々は、あくまでもプラットフォームであり、メディアをつくろうとしているのではない」。広告モデルでないため、PVを稼ぐために大量の低品質SEO記事を量産するインセンティブが構造的に存在しない。WELQの崩壊は「PV＝収益」がクラウドソーシングによる無責任な大量生産を駆動したことが根因であり、noteはその駆動輪を持っていない。
  • C記名・単体課金＝責任の所在が個人に帰属する。WELQは匿名ライターが企業ブランドの下で書き、責任が拡散した。noteは記事がクリエイター個人に紐づき、課金が発生する。書き手が自分の名前と売上を賭けている。
  • A返金機能を先に作った（2019年12月11日）。有料コンテンツの品質不良に対して、モデレーションではなく経済的な是正手段を用意した。プラットフォームが全記事を審査する必要がない。
  • A危機の都度、事前に手を打った。COVID-19関連記事への注意書き表示を2020年1月29日——国内での本格的な情報混乱が起きる前——に実装。
  • A発注経路そのものを明文で規律した（2021年6月28日）。「企業・団体がクリエイターにコンテンツ制作を依頼するときのガイドライン」「クリエイターが第三者からの依頼で制作するときのガイドライン」を同時公開。WELQ型の崩壊は「企業→クラウドワーカー→大量記事」という発注経路で起きた。noteは同じ経路がプラットフォーム上に生まれることを見越し、上流に設計介入した。

売上高 41.4億円（前年比+25.0%）、営業利益 2.5億円（+384.7%）、当期純利益 4.40億円（+345.4%）。会員登録 1,114万人、MAU 8,660万、PVは前年4Q比1.6倍。2Q時点の流通総額 5,205百万円（+24.7%）、note pro有料契約 865件。

WELQは「トラフィックを最大化する仕組み」を作り、noteは「書き手が報われる仕組み」を作った。同じCGMでも、報酬の出所が広告主かユーザーかで、生成されるコンテンツの品質分布が正反対に決まる。

楽天ラクマ vs メルカリ アッテ等のC2C新規事業

対照パターン：P5 親会社の戦略転換 ／ 2012（フリル）／2014（ラクマ）– 稼働中

P5を克服

なぜ生き残ったのか

  • A自社で戦わず、2位を買った。2016年9月5日、楽天がフリル運営のFablicを完全子会社化。C2Cは流動性が勝負なので、2つの中規模市場を1つにするのが唯一の非対称手だった。2018年2月26日に新「ラクマ」へ一本化し、年間流通総額1,000億円超に。
  • A手数料を「武器」として段階的に使った。統合直後は無料 → 2018年6月に3.5% → 2021年1月に6.0%。メルカリ10%に対し常に明確な価格差を維持しながら粗利を段階的に回収した。一気に10%へ揃えず、差分をユーザー獲得原資として温存し続けた。
  • A楽天経済圏という外部補助。ポイント経済圏に接続され、単体でCACを回収する必要がない。グループのリテンション装置として存在できる。
  • A戦場をずらした（2022年4月5日）。「楽天ラクマ」へリブランドし「ラクマ公式ショップ」を開始、リユース事業者130社以上と連携。メルカリと同じ土俵で個人出品者を奪い合うのをやめ、プロの検品・真贋判定による「安心安全」へ差別化軸を置き換えた。2025年に公式ショップが前年比約142%成長。
  • C単体の損益を問われない位置に居続けた。楽天はラクマ単体のGMVすら開示せず、国内EC流通総額6兆3,452億円（2025年度）の構成要素として括っている。独立採算のKPIで評価されないことが、10年単位で耐久する許可証になっている（開示形態からの推論）。

失敗事例との対比

同じ親会社傘下の新規事業でも、メルカリ アッテは独立サービスとして単体の成長性を問われ、ラクマは楽天経済圏の一機能として問われなかった。C2C新規事業の生死を分けたのは市場規模ではなく、親会社がその事業に課すKPIの種類である。

ココナラ vs teacha / タイムバンク

対照パターン：P2 UE不成立／P6 ブーム依存 ／ 2012 –（2021.03 東証マザーズ上場）

P2を克服

なぜ生き残ったのか

  • Aテイクレート約30%を維持している。一般的なマーケットプレイスの2〜3倍。27.6%（FY2024 1Q）→ 28.1%（FY2025 1Q）→ 29.1%（FY2025 3Q）→ 約30%（FY2025通期）と4四半期連続で上昇。これは取引がプラットフォーム内で完結し、外部への離脱が起きていないことの証拠。スキルシェアの典型的な死因は「一度マッチングしたら次から直接取引される」だが、ココナラはこれを抑え込んでいる。
  • C「時間」ではなく「成果物」を売った。teacha／タイムバンク型が「人の時間枠」を商材にしたのに対し、ココナラは760種類以上のカテゴリで納品物単位の取引を扱う。時間枠は日時が合わないと消滅する腐る在庫だが、成果物の依頼は非同期で成立する。流動性要件が根本的に緩い。
  • A供給側を先に厚く積んだ。スキル登録者は毎四半期+32〜37%で伸び120万人超。購入UUが16万人前後で横ばいでも、1出品者あたりの取引依存度が低いため供給が離脱しない。需要が細っても供給が崩れないマーケットプレイスは死なない。
  • A法人需要へ軸足を移した。法人属性会員50万人超、法律相談セグメント+15.9%。個人間のスポット取引から反復・高単価の法人発注へ収益構造を移した。
  • AAIによる低単価需要の蒸発を認めた上で、AIを流入チャネルにした。購入UU数のマイナスをAI影響として公式に説明しつつ、2026年に「ココナラ for ChatGPT」「ココナラ for Claude」を投入。自分を殺しに来た技術を流入経路に変換した。

数値（2025年8月期 通期）

売上高 前年同期比+42.8%（過去最高）、営業利益 約2.5億円（営業黒字）。マーケットプレイス（法律相談除く）：流通総額+4.6%、売上高+8.3%、テイクレート約30%を維持。スキル登録者120万人超、会員登録累計500万人超。※連結の高成長はM&A（ココナラテック）寄与が大きく、マーケットプレイスのオーガニック成長は+8%台。

失敗事例との対比

タイムバンク型は「有名人の時間」という供給が構造的に有限で、しかも時間枠は売れ残ると消滅する在庫だった。ココナラは供給を無名の120万人に分散し、商材を腐らない成果物にした。同じ「スキルを売る」でも、在庫が時間か納品物かで、流動性の要求水準が一桁違う。

F

Adam byGMO vs LINE NFT / VALU

対照パターン：P6 ブーム依存／P3 規制未整備 ／ 2021.08 – 稼働中

P6を克服P3を克服

なぜNFTバブル崩壊を生き延びたのか

  • A円建て決済で暗号資産規制を回避。クレジットカード・銀行振込に対応し、暗号資産を持たないユーザーに開かれた。VALUが倒れた「カストディを持つ」設計を最初から避けている。
  • A投機ではなくリアル体験の権利証へ転換。2025年9月時点で酒蔵ツアー参加権付きNFTチケット等、役務提供の裏付けがある商材へ完全ピボット。VALUが規制回避のために削った「優待」を、Adamは実体を持たせて中核に置いた。
  • C金融グループ傘下で規制対応コストを吸収できた。

ユーザー数10万人突破（2023年7月）、流通アイテム5万4千点超。2026年9月現在も稼働中。

失敗事例との対比

VALUが失敗した「カストディを持たない」「優待に実体を持たせる」の2点を、Adam byGMOは成功させている。ブーム依存からの脱出は、ブーム後に残る実需に商材を接続できるかで決まる。

対照群からの反証：パターンは「運命」ではない

6件すべてが、失敗側とまったく同じ罠に入っている。生死を分けたのは以下の4点で、いずれもプロダクトの巧拙ではなく、事業構造の置き方である。

  • 資本の深さと、その深さに見合った参入判断（PayPay vs Origami）
  • 制度を利用するか、埋めに行くか（LUUP vs VALU）
  • 報酬の出所が広告主かユーザーか（note vs WELQ）
  • 親会社が課すKPIの種類——単独採算か、経済圏のリテンション装置か（ラクマ vs メルカリ アッテ）

終了告知の語彙辞典

「表の理由」の原文を横断すると、日本企業の終了告知は問題の粒度を一段下げて記述するという共通則を持つ。構造的欠陥を、手続き的ミス・市場環境・戦略的選択のいずれかに翻訳する。

公式表現出現実際に意味していること実態との距離
「経営資源を集中／再配置」メルカリ アッテ、メルカリNOW他、LINE LIVE、LINEドクターグループの資本配分判断。事業単体の成否とは無関係遠い
「選択と集中」「一本化」LINE Pay、LINEドクター、カウルグループ内カニバリゼーションの解消やや遠い
「市場の変化」「競合環境」DiDi Food、Chompy、Yahoo!ブログ資本力で負けた、または本社が資本を引いた遠い
「同意取得の不備」リクナビDMPフォロー脱法スキームの設計そのものが問題（PPCが「特定回避の試み」と認定）最も遠い
「満足するサービスの提供に至らない」Yahoo!スコア自社のオプトイン化で母集団が消滅し、商品が成立しなくなった遠い
「シナジーを追求」「事業成長の加速」J.Score競争劣位とグループ重複。ネガティブ要因への言及ゼロ遠い
「リニューアルに伴う」LINE NFT国内法人から国外法人への移管＝規制コストの切り離し遠い
「名称変更します／提供内容に変更はありません」タイムバンク→Let旧モデルの敗北を認めない形の撤退。同年度に総資産を上回る純損失最も遠い
（日程の羅列のみ／告知なし）Origami Pay、LINE CLOVA、グノシーQ説明すれば破綻・不正・非公式性に触れざるを得ない測定不能
「規制に対応できず断念」VALUほぼそのとおり（ライセンスコスト高騰、買収先なし）近い
「機能の大部分が本体にも追加されたことから」メルカリ カウルそのとおり。公式が機能吸収を原因と明記一致
「採算面や、システム維持のテクノロジーに関する複数の課題」Yahoo!ジオシティーズそのとおり。「採算面」を挙げた唯一の例一致
「強みと考えていた機能を十分に活かすことができず」ゆうちょPayそのとおり。戦略仮説の不成立を自認した唯一の例一致

読み解きの原則

公式文言と、官報決算公告・行政処分公表文・有報との差分こそが分析対象。「経営資源の集中」と書かれていたら、その時点の純損失・累積損失・親会社の統合発表を必ず突き合わせる。そして何も書かれていない撤退が、最も深い毀損を隠している。

08

実務チェックリスト

新規サービスの企画・投資判断・撤退設計、および取引先の継続性評価に使う。各項目は本カタログの事例に紐づく。

A. 企画ゲート（ローンチ前）

  • 対象者本人向けの説明文を1ページ書けるか。書けないなら作らない → リクナビ／Yahoo!スコア
  • 損益分岐の客単価を1本の式で書き、市場の実勢単価と比較したか → Chompy
  • 最も保守的な同意設計（オプトイン）で事業が成立するか → Yahoo!スコア
  • 収益機構の実装期限が、成長KPIと同格のマイルストーンに置かれているか → メルカリ アッテ
  • 中核機能が「本体アプリに実装されたら終わるもの」でないか → メルカリ カウル
  • 該当業法の位置づけを利用規約に書けるか。書けないなら制度階段を先に登る → VALU／LUUP
  • 勝者総取り市場に、2番手の資本で入っていないか → Origami Pay

B. 運営ゲート（四半期レビュー）

  • 量的KPIに対する同格の質的ゲートが設定されているか（監修者1人あたり生産量の上限等） → WELQ
  • 法務部への事業部からの照会件数を、牽制機能の稼働指標として経営が見ているか → WELQ
  • 供給側の1人あたり処理数・所要時間の分布に異常値がないか → LINEヘルスケア
  • 累計獲得は伸びているのにアクティブが減っていないか → Clubhouse
  • 視聴／閲覧→実参加のコンバージョンが5%を割っていないか → グノシーQ
  • 1取引の変動費÷平均単価が40%を超えていないか → Chompy
  • 単独KPIが決算資料・IRに昇格しているか。活動報告のままなら、社内でその事業は存在していない → グノシーQ

C. 撤退設計（判断の前後）

  • 撤退基準を立ち上げ時に数値で決めたか。決めていなければ「辞め時を見失う」 → ソウゾウ
  • ピボット先を並走させているか。Chompyは終了の1年8ヶ月前から → Chompy
  • 移行先が社内か社外か。社外ならカテゴリからの完全撤退である → Yahoo!ブログ
  • 処分が見込まれる場合、自主的な撤退を先出しするか（SBI SLは処分の15日前） → SBI SL
  • 終了リリースに理由を書けるか。書けない撤退は、後の再挑戦の信用も失う → Origami／CLOVA／グノシーQ
  • ユーザー資産・債権の管理義務を、終了スケジュールに織り込んだか → VALU／maneo

D. 取引先・依存先の継続性評価

  • 四半期：料金ページのWayback差分、公式お知らせ一覧、アプリ更新履歴
  • 半期：官報決算公告（純損失／総資産）、有報の記述変化、調達履歴
  • イベント駆動：親会社の統合発表、同業他社への行政処分、カテゴリ内の他社撤退
  • 外資子会社なら、現地ではなく親会社の株価・規制・上場ステータス・他国での撤退を見る → foodpanda／DiDi Food
  • 単独KPIが一度も公表されていないサービスを、基幹業務の依存先にしない
  • 「エリア拡大」「新規出店」「大型コラボ」を安全シグナルとして読まない

新サービス設計への含意：3つの問い

27件の失敗と6件の生存を貫く問いは、結局この3つに収束する。

  • ①「この事業は、誰の資本で、何ヶ月生きられるか」——資本力勝負の市場に入るなら、勝つ側の資本を持っているか、持っている側と組むか、そもそも入らないかの三択しかない。
  • ②「制度の空白を、利用するのか埋めるのか」——利用する側は当局が態度を決めた瞬間に二択（登録か撤退か）へ収斂する。埋める側は制度そのものを参入障壁にできる。
  • ③「親会社は、この事業に何のKPIを課すのか」——単独採算を課される新規事業は「絶対規模と機会費用」で切られ、経済圏のリテンション装置として位置づけられた事業は10年単位で生きる。この設計は、プロダクトを作る前に決まる。

制約（正直な記載）

  • Wayback Machine（web.archive.org）は調査環境からブロックされた。設計書にあった「Waybackでの料金・機能ページ変遷」は、公式リリース・報道・官報・有報で代替している。料金改定の事実（LINE Pay 0%→2.45%、ラクマ 無料→3.5%→6.0%）は一次資料で確認済み。継続的な定点観測としてのWayback差分監視は、実務側で別途セットアップすることを推奨。
  • App Store／Google Playの更新停止時期は、公開データとして取得できなかった。代替として「新規ダウンロード停止」「配信頻度削減」「新モデル投入停止」の公式告知で兆候を代替している。
